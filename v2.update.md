# YeppAds V2 update migration



## 1. Outlet -> Location (Migrated)

 1. Changed base location route
    - **POST** `/locations`  Location create
    - **PATCH** `/locations` Update location

 2. replaced **outlet_name** name by `location_name` 

 3. Added **nationwide** field in Ads/Deal schema. If deal has **nationwide:true** that means that Deal/Ads are available whole country. If **nationwide: false** that means Deal/Ads are available in limited location.

 4. Updated shop analytics API. Added 3 new fields **totalDeals**, **expireDeals** and **newDeals**.

 5. Created new Apis for Set Location and get Deals. Routes is **/deals/location**.

 6. Create vendors information **CSV/XLSX** download/export apis for dashboard

 7. Created location bulk upload by **CSV/XLSX** file.

 8. Added **custom_discount** field to the deal schema, supported in both create and update APIs.
